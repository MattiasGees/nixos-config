# vmctl Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Go/Cobra CLI (`vmctl`) that creates/destroys/lists throwaway QEMU-KVM VMs (Ubuntu LTS / NixOS) on polaris with consistent LAN static IPs via cloud-init and thin qcow2 overlays on ZFS scratch, plus the NixOS-config wiring to install and configure it.

**Architecture:** The Go tool is generic and libvirt-host-agnostic: every external call goes through a `Runner` interface (fake in tests, `os/exec` in prod), and all polaris-specifics (bridge, VMROOT, gateway/DNS, key source, image paths) are injected as environment variables by a NixOS module wrapper. Two repos: `MattiasGees/vmctl` (the CLI + a nixos-generators base image, own CI/releases) consumed by `nixos-config` as a flake input.

**Tech Stack:** Go 1.22+, Cobra, libvirt CLI tooling (`virsh`, `virt-install`, `qemu-img`, `cloud-localds`), Nix flakes (`buildGoModule`, `nixos-generators`), GitHub Actions + GoReleaser.

## Global Constraints

- **Design spec:** `docs/superpowers/specs/2026-08-03-vmctl-design.md` — authoritative; this plan implements it.
- **Repos & branches:** vmctl work on branch `feat/initial-implementation` (off `main`), PR → **`main`**. nixos-config work on branch `feat/vmctl` (off `mattias`), PR → **`mattias`** (NOT `master`). Both branches already exist.
- **vmctl local checkout:** `/Users/mattias/Documents/git/vmctl` (remote `git@github.com:MattiasGees/vmctl.git`). nixos-config: `/Users/mattias/Documents/git/nixos-config`.
- **Testability seam is mandatory:** all external commands go through `runner.Runner`; all validation / rendering / parsing are pure functions. No package calls `os/exec` except `runner.ExecRunner`.
- **No polaris-specifics in Go code.** Defaults come from `VMCTL_*` env vars, overridable by flags.
- **Per-VM defaults:** `--os ubuntu`, `--cpu 2`, `--mem 2G`, `--disk 20G`. Required: name + `--ip`.
- **Env-var config keys:** `VMCTL_BRIDGE`, `VMCTL_VMROOT`, `VMCTL_GATEWAY`, `VMCTL_DNS`, `VMCTL_USER`, `VMCTL_SSH_KEYS_URL`, `VMCTL_NIXOS_BASE`, `VMCTL_UBUNTU_URL`, `VMCTL_UBUNTU_SHA256`, `LIBVIRT_DEFAULT_URI` (optional; defaults to `qemu:///system`).
- **libvirt metadata namespace:** URI `https://github.com/MattiasGees/vmctl`, key `vmctl`.
- **Memory unit:** MiB integers for `virt-install --memory`. **Disk unit:** GiB integers for `qemu-img`/`--disk`.
- **Commit frequently** (each task's final step). Every code step is TDD: failing test → run (fail) → minimal impl → run (pass) → commit.
- **Verification for NixOS parts:** `nix build` success is the bar (no CI in nixos-config); vmctl parts add `go test` + CI.
- **Nix commands:** set `NIX_CONFIG="experimental-features = nix-command flakes"`; nixos-config builds pass `--impure` per its Makefile.

`internal/validate/validate.go`:
```go
package validate

import (
	"fmt"
	"net"
	"regexp"
	"strconv"
	"strings"
)

var nameRe = regexp.MustCompile(`^[a-z0-9]([a-z0-9-]{0,30}[a-z0-9])?$`)

func Name(s string) error {
	if !nameRe.MatchString(s) {
		return fmt.Errorf("invalid name %q: use lowercase letters, digits, hyphens (2-32 chars, no leading/trailing hyphen)", s)
	}
	return nil
}

func IPv4(s string) error {
	ip := net.ParseIP(s)
	if ip == nil || ip.To4() == nil {
		return fmt.Errorf("invalid IPv4 address %q", s)
	}
	return nil
}

func OS(s string) (string, error) {
	switch strings.ToLower(s) {
	case "ubuntu":
		return "ubuntu", nil
	case "nixos":
		return "nixos", nil
	default:
		return "", fmt.Errorf("unknown OS %q: want ubuntu or nixos", s)
	}
}

func MemoryMiB(s string) (int, error) {
	n, unit, err := splitSize(s)
	if err != nil {
		return 0, err
	}
	switch unit {
	case "M":
		return n, nil
	case "G":
		return n * 1024, nil
	default:
		return 0, fmt.Errorf("memory %q: use M or G suffix", s)
	}
}

func DiskGiB(s string) (int, error) {
	n, unit, err := splitSize(s)
	if err != nil {
		return 0, err
	}
	if unit != "G" {
		return 0, fmt.Errorf("disk %q: use G suffix", s)
	}
	return n, nil
}

func splitSize(s string) (int, string, error) {
	s = strings.TrimSpace(s)
	if len(s) < 2 {
		return 0, "", fmt.Errorf("invalid size %q", s)
	}
	unit := strings.ToUpper(s[len(s)-1:])
	n, err := strconv.Atoi(s[:len(s)-1])
	if err != nil || n <= 0 {
		return 0, "", fmt.Errorf("invalid size %q", s)
	}
	return n, unit, nil
}
```

package config

import "path/filepath"

type Config struct {
	Bridge, VMRoot, Gateway, DNS, User            string
	SSHKeysURL, NixOSBase, UbuntuURL, UbuntuSHA256 string
	LibvirtURI                                    string
}

func Resolve(getenv func(string) string) Config {
	def := func(key, fallback string) string {
		if v := getenv(key); v != "" {
			return v
		}
		return fallback
	}
	return Config{
		Bridge:       def("VMCTL_BRIDGE", "virbr0"),
		VMRoot:       def("VMCTL_VMROOT", "/var/lib/vmctl"),
		Gateway:      def("VMCTL_GATEWAY", ""),
		DNS:          def("VMCTL_DNS", ""),
		User:         def("VMCTL_USER", "root"),
		SSHKeysURL:   def("VMCTL_SSH_KEYS_URL", ""),
		NixOSBase:    def("VMCTL_NIXOS_BASE", ""),
		UbuntuURL:    def("VMCTL_UBUNTU_URL", ""),
		UbuntuSHA256: def("VMCTL_UBUNTU_SHA256", ""),
		LibvirtURI:   def("LIBVIRT_DEFAULT_URI", "qemu:///system"),
	}
}

func (c Config) BaseDir() string  { return filepath.Join(c.VMRoot, "base") }
func (c Config) DisksDir() string { return filepath.Join(c.VMRoot, "disks") }
func (c Config) SeedsDir() string { return filepath.Join(c.VMRoot, "seeds") }

func (c Config) OverlayPath(name string) string { return filepath.Join(c.DisksDir(), name+".qcow2") }
func (c Config) SeedPath(name string) string    { return filepath.Join(c.SeedsDir(), name+"-seed.iso") }
func (c Config) UbuntuBasePath() string         { return filepath.Join(c.BaseDir(), "ubuntu-cloudimg.qcow2") }
func (c Config) NixOSBasePath() string          { return filepath.Join(c.BaseDir(), "nixos-base.qcow2") }

	return b.String(), nil

func ParseKeys(r io.Reader) ([]string, error) {
	var keys []string

	for sc.Scan() {
		line := strings.TrimSpace(sc.Text())
		if line == "" || strings.HasPrefix(line, "#") {
			continue
		}
		keys = append(keys, line)
	}
	if err := sc.Err(); err != nil {
		return nil, err
	}
	if len(keys) == 0 {
		return nil, fmt.Errorf("no ssh keys found")
	}
	return keys, nil
}

	Stderr string

	cmd.Stdout = &out
	cmd.Stderr = &errb
	err := cmd.Run()
	return out.String(), errb.String(), err
}

		return r.Stdout, r.Stderr, r.Err
	}
	return f.Default.Stdout, f.Default.Stderr, f.Default.Err

	_, _, err := c.virsh(ctx, "dominfo", name)
	if err != nil {
		return false, nil // non-zero exit → does not exist (virsh prints to stderr)

func (c *Client) DomInfo(ctx context.Context, name string) (DomState, error) {
	out, _, err := c.virsh(ctx, "dominfo", name)
	if err != nil {
		return DomState{}, fmt.Errorf("dominfo %s: %w", name, err)
	}
	ds, err := parseDomInfo(out)
	ds.Name = name
	return ds, err
}

func parseDomInfo(out string) (DomState, error) {
	ds := DomState{}
	for _, line := range strings.Split(out, "\n") {
		k, v, ok := strings.Cut(line, ":")
		if !ok {
			continue
		}
		v = strings.TrimSpace(v)
		switch strings.TrimSpace(k) {
		case "State":
			ds.State = v
		case "CPU(s)":
			ds.VCPUs, _ = strconv.Atoi(v)
		case "Max memory":
			// "2097152 KiB"
			fields := strings.Fields(v)
			if len(fields) > 0 {
				kib, _ := strconv.Atoi(fields[0])
				ds.MemMiB = kib / 1024
			}
		}
	}
	return ds, nil
}

func (c *Client) ListNames(ctx context.Context) ([]string, error) {
	out, _, err := c.virsh(ctx, "list", "--all", "--name")
	if err != nil {
		return nil, err
	}
	var names []string
	for _, l := range strings.Split(out, "\n") {
		if l = strings.TrimSpace(l); l != "" {
			names = append(names, l)
		}
	}
	return names, nil
}

func (c *Client) SetMeta(ctx context.Context, name string, m meta.Meta) error {
	_, stderr, err := c.virsh(ctx, "metadata", name,
		"--uri", metaURI, "--key", "vmctl", "--set", m.Fragment(), "--config", "--live")
	if err != nil {
		// --live fails on a stopped domain; retry config-only.
		_, stderr, err = c.virsh(ctx, "metadata", name, "--uri", metaURI, "--key", "vmctl", "--set", m.Fragment(), "--config")
	}
	if err != nil {
		return fmt.Errorf("set metadata: %v: %s", err, stderr)
	}
	return nil
}

	out, _, err := c.virsh(ctx, "metadata", name, "--uri", metaURI, "--key", "vmctl", "--config")
	if err != nil {
		return meta.Meta{}, err
	}
	return meta.Parse(strings.TrimSpace(out))
}

	_, stderr, err := c.R.Run(ctx, "virt-install", args...)

	}
	return nil

	_, se, err := c.virsh(ctx, "start", name)

	}
	return nil
}

	verb := "shutdown"
	if force {
		verb = "destroy"
	}
	_, se, err := c.virsh(ctx, verb, name)
	if err != nil {
		return fmt.Errorf("%s %s: %v: %s", verb, name, err, se)
	}
	return nil

	return nil

	if err != nil {
		return fmt.Errorf("undefine %s: %v: %s", name, err, se)
	}
	return nil

import (
	"context"
	"fmt"
	"strings"

	"github.com/MattiasGees/vmctl/internal/cloudinit"
	"github.com/MattiasGees/vmctl/internal/config"
	"github.com/MattiasGees/vmctl/internal/libvirt"
	"github.com/MattiasGees/vmctl/internal/meta"
	"github.com/MattiasGees/vmctl/internal/runner"
)

type Spec struct {
	Name, OS, IP string
	CPUs, MemMiB, DiskGiB int
}

type FileSystem interface {
	MkdirAll(string) error
	WriteFile(path string, data []byte) error
	Remove(path string) error
	Exists(path string) bool
}

type KeyFetcher func(url string) ([]string, error)

type Manager struct {
	Cfg  config.Config
	LV   *libvirt.Client
	R    runner.Runner
	FS   FileSystem
	Keys KeyFetcher
}

func (m *Manager) basePath(os string) string {
	if os == "nixos" {
		return m.Cfg.NixOSBasePath()
	}
	return m.Cfg.UbuntuBasePath()
}

func (m *Manager) Create(ctx context.Context, s Spec) (bool, error) {
	exists, err := m.LV.DomainExists(ctx, s.Name)
	if err != nil {
		return false, err
	}
	if exists {
		return false, nil // idempotent no-op
	}
	if err := m.ensureBase(ctx, s.OS); err != nil {
		return false, err
	}
	for _, d := range []string{m.Cfg.DisksDir(), m.Cfg.SeedsDir()} {
		if err := m.FS.MkdirAll(d); err != nil {
			return false, err
		}
	}
	overlay := m.Cfg.OverlayPath(s.Name)
	seed := m.Cfg.SeedPath(s.Name)
	cleanup := func() { m.FS.Remove(overlay); m.FS.Remove(seed) }

	if err := libvirt.CreateOverlay(ctx, m.R, m.basePath(s.OS), overlay, s.DiskGiB); err != nil {
		cleanup()
		return false, err
	}
	if err := m.buildSeed(ctx, s, seed); err != nil {
		cleanup()
		return false, err
	}
	if err := m.LV.VirtInstall(ctx, m.virtInstallArgs(s, overlay, seed)...); err != nil {
		cleanup()
		return false, err
	}
	if err := m.LV.SetMeta(ctx, s.Name, meta.Meta{OS: s.OS, IP: s.IP}); err != nil {
		// The domain is already defined and running; do NOT remove its disk.
		// Signal created=true so the caller knows the VM exists but is
		// unrecorded (invisible to list/ssh until its metadata is re-tagged).
		return true, fmt.Errorf("VM %s created but metadata write failed (not visible to list/ssh until re-tagged): %w", s.Name, err)
	}
	return true, nil
}

func (m *Manager) ensureBase(ctx context.Context, os string) error {
	base := m.basePath(os)
	if m.FS.Exists(base) {
		return nil
	}
	if err := m.FS.MkdirAll(m.Cfg.BaseDir()); err != nil {
		return err
	}
	if os == "nixos" {
		if m.Cfg.NixOSBase == "" {
			return fmt.Errorf("VMCTL_NIXOS_BASE not set")
		}
		_, _, err := m.R.Run(ctx, "cp", "--reflink=auto", m.Cfg.NixOSBase, base)
		return err
	}
	if m.Cfg.UbuntuURL == "" {
		return fmt.Errorf("VMCTL_UBUNTU_URL not set")
	}
	if _, se, err := m.R.Run(ctx, "curl", "-fsSL", "-o", base, m.Cfg.UbuntuURL); err != nil {
		return fmt.Errorf("download ubuntu image: %v: %s", err, se)
	}
	if m.Cfg.UbuntuSHA256 != "" {
		out, _, err := m.R.Run(ctx, "sha256sum", base)
		if err != nil || !strings.HasPrefix(out, m.Cfg.UbuntuSHA256) {
			m.FS.Remove(base)
			return fmt.Errorf("ubuntu image checksum mismatch")
		}
	}
	return nil
}

func (m *Manager) buildSeed(ctx context.Context, s Spec, seed string) error {
	keys, err := m.Keys(m.Cfg.SSHKeysURL)
	if err != nil {
		return err
	}
	ud, err := cloudinit.UserData(s.Name, m.Cfg.User, keys)
	if err != nil {
		return err
	}
	nc, err := cloudinit.NetworkConfig(s.IP, m.Cfg.Gateway, m.Cfg.DNS)
	if err != nil {
		return err
	}
	md := cloudinit.MetaData(s.Name)
	udPath, mdPath, ncPath := seed+".user", seed+".meta", seed+".net"
	for p, data := range map[string]string{udPath: ud, mdPath: md, ncPath: nc} {
		if err := m.FS.WriteFile(p, []byte(data)); err != nil {
			return err
		}
	}
	_, se, err := m.R.Run(ctx, "cloud-localds", "--network-config", ncPath, seed, udPath, mdPath)
	if err != nil {
		return fmt.Errorf("cloud-localds: %v: %s", err, se)
	}
	return nil
}

func (m *Manager) virtInstallArgs(s Spec, overlay, seed string) []string {
	variant := "ubuntu24.04"
	if s.OS == "nixos" {
		variant = "nixos-unknown"
	}
	return []string{
		"--connect", m.Cfg.LibvirtURI,
		"--name", s.Name,
		"--vcpus", fmt.Sprintf("%d", s.CPUs),
		"--memory", fmt.Sprintf("%d", s.MemMiB),
		"--os-variant", variant,
		"--disk", "path=" + overlay + ",format=qcow2,bus=virtio",
		"--disk", "path=" + seed + ",device=cdrom",
		"--network", "bridge=" + m.Cfg.Bridge + ",model=virtio",
		"--graphics", "none",
		"--console", "pty,target_type=serial",
		"--import",
		"--autostart",
		"--noautoconsole",
	}
}

func (m *Manager) Destroy(ctx context.Context, name string) error {
	exists, err := m.LV.DomainExists(ctx, name)
	if err != nil {
		return err
	}
	if !exists {
		return fmt.Errorf("no such VM: %s", name)
	}
	m.LV.DestroyDomain(ctx, name)
	if err := m.LV.Undefine(ctx, name); err != nil {
		return err
	}
	m.FS.Remove(m.Cfg.OverlayPath(name))
	m.FS.Remove(m.Cfg.SeedPath(name))
	return nil
}

type ListRow struct {
	Name, OS, IP, State string
	VCPUs, MemMiB       int
}

func (m *Manager) List(ctx context.Context) ([]ListRow, error) {
	names, err := m.LV.ListNames(ctx)
	if err != nil {
		return nil, err
	}
	var rows []ListRow
	for _, n := range names {
		ds, err := m.LV.DomInfo(ctx, n)
		if err != nil {
			continue
		}
		md, _ := m.LV.GetMeta(ctx, n) // absent metadata → empty os/ip (not a vmctl VM)
		rows = append(rows, ListRow{Name: n, OS: md.OS, IP: md.IP, State: ds.State, VCPUs: ds.VCPUs, MemMiB: ds.MemMiB})
	}
	return rows, nil
}

type InfoRow struct {
	ListRow
	DiskUsed, DiskMax int64
	Backing           string
}

func (m *Manager) Info(ctx context.Context, name string) (InfoRow, error) {
	ds, err := m.LV.DomInfo(ctx, name)
	if err != nil {
		return InfoRow{}, err
	}
	md, _ := m.LV.GetMeta(ctx, name)
	di, _ := libvirt.QemuImgInfo(ctx, m.R, m.Cfg.OverlayPath(name))
	return InfoRow{
		ListRow:  ListRow{Name: name, OS: md.OS, IP: md.IP, State: ds.State, VCPUs: ds.VCPUs, MemMiB: ds.MemMiB},
		DiskUsed: di.ActualBytes, DiskMax: di.VirtualBytes, Backing: di.Backing,

func (m *Manager) SSHTarget(ctx context.Context, name string) (string, string, error) {
	md, err := m.LV.GetMeta(ctx, name)
	if err != nil {
		return "", "", err
	}
	if md.IP == "" {
		return "", "", fmt.Errorf("no recorded IP for %s", name)
	}
	return m.Cfg.User, md.IP, nil
}

  inputs = {
    nixpkgs.url = "github:nixos/nixpkgs/nixos-unstable";
    flake-utils.url = "github:numtide/flake-utils";
    nixos-generators = {
      url = "github:nix-community/nixos-generators";

  outputs = { self, nixpkgs, flake-utils, nixos-generators }:
    flake-utils.lib.eachDefaultSystem (system:

        # nixpkgs); vmctl create shells out to it. libvirt provides virsh.
        runtimeDeps = with pkgs; [ libvirt virt-manager qemu-utils cloud-utils openssh coreutils curl ];
      in

        packages.vmctl = pkgs.buildGoModule {
          pname = "vmctl";
          version = "0.1.0";
          src = ./.;
          # FINAL DECISION (superseding the "commit vendor/" note below): the repo
          # is kept lean — vendor/ is NOT committed. vendorHash is a fakeHash
          # placeholder; the first `nix build .#vmctl` on a nix machine prints the
          # real sha256 to paste in. (Steps 3-5 below originally vendored; the repo
          # now uses this vendorHash instead.)
          vendorHash = pkgs.lib.fakeHash;
          nativeBuildInputs = [ pkgs.makeWrapper ];
          postInstall = ''
            wrapProgram $out/bin/vmctl \
              --prefix PATH : ${pkgs.lib.makeBinPath runtimeDeps}
          '';
          meta.mainProgram = "vmctl";
        };

        packages.nixos-base =
          if system == "x86_64-linux" || system == "aarch64-linux" then
            nixos-generators.nixosGenerate {
              inherit system;
              format = "qcow";
              modules = [ ./nix/nixos-base.nix ];

          else pkgs.hello; # placeholder on non-Linux; not used

        devShells.default = pkgs.mkShell {
          packages = with pkgs; [ go gopls golangci-lint ] ++ runtimeDeps;

**Files:**

- [ ] **Step 1: Write the module**

`modules/server/vmctl.nix`:
```nix
# vmctl — KVM VM lab CLI (github.com/MattiasGees/vmctl), wired for polaris.
# The generic Go tool reads polaris specifics from VMCTL_* env vars set here.
# `vmctlPackages` is injected via _module.args from flake.nix (mkServer does
# not thread flake inputs into modules).
{ pkgs, lib, config, vmctlPackages, ... }:
let
  vmRoot = "/srv/scratch/vms"; # scratch pool native mountpoint (confirm on-host)
  nixosBase = "${vmctlPackages.nixos-base}/nixos.qcow2";
  # Ubuntu 24.04 LTS cloud image — pin URL + sha256 (fill sha on first fetch).
  ubuntuURL = "https://cloud-images.ubuntu.com/releases/24.04/release/ubuntu-24.04-server-cloudimg-amd64.img";
  ubuntuSHA = ""; # TODO(on-host): set to the pinned image's sha256
  vmctlWrapped = pkgs.symlinkJoin {
    name = "vmctl-wrapped";
    paths = [ vmctlPackages.vmctl ];
    nativeBuildInputs = [ pkgs.makeWrapper ];
    postBuild = ''
      wrapProgram $out/bin/vmctl \
        --set VMCTL_BRIDGE "br0" \
        --set VMCTL_VMROOT "${vmRoot}" \
        --set VMCTL_GATEWAY "192.168.1.1" \
        --set VMCTL_DNS "192.168.1.1" \
        --set VMCTL_USER "mattias" \
        --set VMCTL_SSH_KEYS_URL "https://github.com/mattiasgees.keys" \
        --set VMCTL_NIXOS_BASE "${nixosBase}" \
        --set VMCTL_UBUNTU_URL "${ubuntuURL}" \
        --set VMCTL_UBUNTU_SHA256 "${ubuntuSHA}"
    '';
  };
in
{
  environment.systemPackages = [ vmctlWrapped ];

  # Ensure the VM storage tree exists on scratch, owned by the operator.
  systemd.tmpfiles.rules = [
    "d ${vmRoot}        0755 mattias libvirtd - -"
    "d ${vmRoot}/base   0755 mattias libvirtd - -"
    "d ${vmRoot}/disks  0755 mattias libvirtd - -"
    "d ${vmRoot}/seeds  0755 mattias libvirtd - -"
  ];
}
```
